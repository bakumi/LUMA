# LUMA

> **LUMA** — ультра-премиальный нативный оверлей для Windows 10/11 в стиле Dynamic Island и Hitodama Control Center.
> Приложение прикреплено к верхнему краю экрана, в неактивном состоянии представляет собой монолитную чёрную выемку 208×19 DIP, а по клику или глобальному хоткею мгновенно и бесшовно раскрывается в мощный центр управления, медиаплеер, системный монитор и лаунчер.

## 🎯 О проекте и концепция

LUMA создана для устранения разрыва между эстетикой современных мобильных UI (iOS Dynamic Island, macOS Notch) и функциональностью настольной Windows. 

### Ключевые визуальные принципы:
* **Нативная геометрия сплайнов (Island Contour Geometry):** Никаких грубых прямоугольников. Выемка выплывает из верхней границы монитора плавной вогнутой волной Безье (`topWave = 18.0 DIP`), переходит в вертикальные прямые грани и замыкается мягкими выпуклыми скруглениями снизу (`bottomCorner = 24.0 DIP`).
* **Zero-Flash Morphing:** Окно имеет постоянные размеры `760×500 DIP`, а анимация открытия и переключения вкладок осуществляется через `ScaleTransform` и динамический `PathGeometry` клиппинг. Это полностью устраняет мерцание прозрачных layered-окон Windows при resize.
* **Глубокий чёрный OLED-фон (`#FF0B0B0E`):** Элементы интерфейса используют тёмные многослойные подложки с микроконтрастными границами (`#FF25252A`), оранжевые акценты (`#FFFF8E5F`) и плавные кинематографичные кривые анимации (`CubicEaseOut`).
* **Адаптивные размеры под контент:** Каждая вкладка раскрывает островок ровно до той высоты и ширины, которая необходима её элементам, без пустого пространства.

## 🛠 Архитектура и стек технологий

* **Среда выполнения:** `.NET 10.0` (`net10.0-windows10.0.19041.0`)
* **UI Фреймворк:** Pure WPF (XAML + C#), без тяжёлых внешних зависимостей.
* **Оконный режим:** `AllowsTransparency=True`, `WindowStyle=None`, `ShowInTaskbar=False`, расширенный стиль `WS_EX_TOOLWINDOW` (окно скрыто из Alt+Tab и панели задач, всегда поверх через `SetWindowPos(HWND_TOPMOST)`).
* **Интеграция с ОС:**
  * **Win32 API:** Регистрация глобальных горячих клавиш (`RegisterHotKey`), управление питанием (`LockWorkStation`, `SetSuspendState`, `shutdown.exe`), смена обоев рабочего стола (`SystemParametersInfoW SPI_SETDESKWALLPAPER`), извлечение системных иконок программ (`SHGetFileInfoW`).
  * **CoreAudio & COM Interfaces:** Управление системной громкостью через `IAudioEndpointVolume`, перечисление конечных точек через `IMMDeviceEnumerator` / `IMMDeviceCollection` / `IPropertyStore`, мгновенное программное переключение аудиоустройства по умолчанию через недокументированный COM-интерфейс `IPolicyConfig`.
  * **Windows Media GSMTC (WinRT):** Перехват метаданных текущего воспроизведения (Spotify, Яндекс.Музыка, Браузеры, плееры) через `GlobalSystemMediaTransportControlsSessionManager`, обложки альбомов через `IRandomAccessStreamWithContentType`, управление треками и плавная интерполяция таймлайна.
  * **Bluetooth & Radios (WinRT + Registry):** Сканирование оборудования и управление питанием адаптера через `Windows.Devices.Radios.Radio`, поиск сопряжённых устройств (`DeviceInformation`, реестр `SYSTEM\CurrentControlSet\Enum\BTHENUM`), подключение через RFCOMM.

## 🧭 Функционал и вкладки

### 1. 🎛 Controls (Пункт управления Hitodama)
* **Размер островка:** `540×320 DIP`.
* **Карточки быстрого доступа:**
  * **Wi-Fi:** Отображает статус; при отсутствии модуля на десктопе сообщает об Ethernet. Клик открывает детальную шторку управления сетью.
  * **Bluetooth:** Раздельная плашка: левая часть включает/выключает радиомодуль, правая стрелочка открывает шторку устройств. При подключении наушников звук автоматически переключается на них; при выключении Bluetooth звук мгновенно возвращается на системные динамики.
  * **Audio:** Показывает реальное имя активного устройства вывода (динамик `\uE767` или наушники `\uE7F6`). Если Bluetooth выключен, отключённые наушники исключаются из списка и никогда не отображаются как активные. Клик открывает шторку мгновенного переключения звука.
  * **Night Light:** Индикатор ночного света Windows.
  * **Dark Mode:** Переключатель системной тёмной/светлой темы Windows через реестр (`AppsUseLightTheme`).
* **Master Volume Slider:** Интерактивная капсула громкости с заполнением, поддержкой drag-and-drop мыши, колеса прокрутки (`MouseWheel`) и изменением иконки динамика в зависимости от уровня.
* **Встроенный мини-плеер:** Обложка, название трека, автор, таймлайн и кнопки управления с переходом во вкладку Player.
* **Шторки-подстраницы внутри островка (Sub-Drawers):**
  * **Sound Output Drawer:** Полный список всех активных аудиовыходов Windows с круглыми бейджами выбора. Клик по любому устройству мгновенно перенаправляет звук системы на него (`IPolicyConfig`) и реактивно обновляет статус в Bluetooth.
  * **Bluetooth Drawer:** Кнопка выключения/включения радиомодуля Bluetooth, список сопряжённых устройств с анимированным пульсирующим лоадером (вместо статического троеточия) и полностью бесшовным обновлением без мерцания экрана.
  * **Wi-Fi Drawer:** Информация об адаптерах и прямой переход к сетевым параметрам Windows.

### 2. 🎙 Voice Assistant & Dictation (Win + Alt)
* **Горячая клавиша:** `Win + Alt` (или `Alt + Win`) из любого приложения Windows.
* **Мини-трансформация закрытой выемки (Top Notch Waveform):**
  * Верхняя закрытая шторка плавно расширяется с 208×19 до 310×24 DIP без открытия основного островка.
  * Слева появляется подсвеченная иконка микрофона.
  * По центру в реальном времени анимируются 7 спектральных полосок звуковой волны (undulating frequency bars).
  * Справа отображается статусное состояние распознавания.
* **Нижняя плавающая капсула ввода (Taskbar Capsule):**
  * Прямо над панелью задач Windows всплывает элегантная скруглённая капсула (`CornerRadius="28"`), оформленная в стиле референса на глубоком чёрном фоне.
  * Бейдж `YOU`, текст речи в реальном времени с мерцающим курсором `|`.
  * Кнопки «Вставить (Enter)» и отмены (`Esc`).
  * По завершении записи или нажатию `Enter` фокус автоматически возвращается в активное текстовое поле на ПК, и распознанный текст мгновенно вставляется через симуляцию `Ctrl+V`.

### 3. 🎵 Player (Медиаплеер)
* **Размер островка:** `480×146 DIP` (компактный и выверенный отступ под кнопками).
* **Живая синхронизация с Windows GSMTC:** Автоматически подтягивает трек из любого активного плеера или браузера (YouTube, Яндекс.Музыка, Spotify, VK).
* **Сглаженная интерполяция таймлайна:** Таймер на 100 мс плавно двигает ползунок без рывков.
* **Формат времени:** `hh:mm:ss` или `mm:ss` в зависимости от длительности.
* **Интерактивный скраббинг:** Перемотка кликом по полосе прогресса.
* **Режим Standalone Player (Фото 1):** Размер `380×118 DIP`, строка вкладок скрыта, остаётся только монолитный плавающий медиаплеер.

### 3. 📊 Stats (Системная диагностика)
* **Размер островка:** `680×275 DIP`.
* **3 круговых датчика (Gauges):**
  * **CPU:** Реальная нагрузка (дельта `GetSystemTimes`), модель процессора из реестра, текущая частота и число процессов.
  * **GPU:** Загрузка видеоядра и объём используемой видеопамяти.
  * **RAM:** Точное использование оперативной памяти через `GlobalMemoryStatusEx` (занято / всего / свободно).
* **Нижние информационные плашки:**
  * **DISK C:** Занятый объём системного диска (`DriveInfo`).
  * **NETWORK:** Текущая скорость приёма ($\downarrow$) и отдачи ($\uparrow$) в байтах/КБ/МБ/с через дельты `NetworkInterface`.
  * **UP FOR:** Аптайм системы со времени загрузки Windows.
* **Топ процессов:** Сортировка по RAM или CPU в один клик.
* **Speed Test:** Карточка быстрого замера скорости интернета.

### 4. 🚀 Apps (Лаунчер и Поиск)
* **Размер островка:** `520×435 DIP`.
* **Поисковая строка:** Поддерживает быстрый вызов по горячей клавише, очистку, историю поисковых запросов.
* **Настоящие установленные программы:** Сканирует `Start Menu` (ProgramData и AppData), извлекает нативные иконки приложений высокого разрешения через `SHGetFileInfoW`.
* **Недавние файлы:** Читает реальные недавние документы из папки `Recent`.
* **Категории:** `STARRED` (избранные), `RECENT` (недавние), `APPLICATIONS` (все программы).
* **Запуск в один клик:** Нажатие запускает процесс через `Process.Start`.

### 5. 🖼 Wallpaper (Галерея обоев Cover Flow)
* **Размер островка:** `720×246 DIP`.
* **3D Cover Flow карусель:** 5 интерактивных карточек с динамическим масштабированием (центральная 1.0, боковые 0.85 и 0.72) и перспективой.
* **Смена обоев рабочего стола:** Клик по карточке мгновенно устанавливает выбранное изображение на рабочий стол Windows через `SystemParametersInfoW`.
* **Поддержка своих папок:** Кнопка «My folder» позволяет выбрать любую локальную папку с обоями.

### 6. ⚡ Power (Питание и сеанс)
* **Размер островка:** `540×140 DIP`.
* **4 действия:**
  * **Lock:** Мгновенная блокировка экрана Windows (`LockWorkStation`).
  * **Sleep:** Перевод в режим сна (`SetSuspendState`).
  * **Restart:** Перезагрузка с 15-секундным таймером отмены.
  * **Shutdown:** Выключение с 15-секундным таймером отмены.
* **Модальное окно подтверждения:** Защищает от случайных нажатий, позволяет отменить выключение клавишей `Esc` или кнопкой отмены (`shutdown /a`).

### 2. COM-интерфейс переключения аудиовыхода (`IPolicyConfig`)
В Windows нет официального Win32 API для смены устройства воспроизведения по умолчанию без открытия системного окна параметров. В `Services/AudioService.cs` реализован COM-интерфейс `IPolicyConfig`:
```csharp
[ComImport]
[Guid("870AF99C-171D-4F9E-AF0D-E63DF40C2BC9")]
private class PolicyConfigClient { }

[Guid("f8679f50-850a-41cf-9c72-430f290290c8"), InterfaceType(ComInterfaceType.InterfaceIsIUnknown)]
private interface IPolicyConfig
{
    // ...
    [PreserveSig]
    int SetDefaultEndpoint([MarshalAs(UnmanagedType.LPWStr)] string wszDeviceId, int role);
}
```
При выборе аудиоустройства в шторке метод `AudioService.SetDefaultAudioEndpoint(deviceId)` назначает его для всех трёх ролей: `eConsole (0)`, `eMultimedia (1)` и `eCommunications (2)`.

### Требования
* Windows 10 (версия 2004 / билд 19041 или новее) / Windows 11.
* Для сборки из исходников: [.NET 10.0 SDK](https://dotnet.microsoft.com/download).

### Быстрый запуск
```cmd
# Запуск проекта из исходников
Start-LUMA.cmd

# Сборка автономного Single-File Executable (artifacts\win-x64\LUMA.exe)

* **Открыть / Закрыть островок:** Клик по компактной выемке или глобальный хоткей `Ctrl + Shift + Space`.

- Размер окна постоянен: 760×500 DIP. Менять Window.Width / Window.Height по кадрам СТРОГО ЗАПРЕЩЕНО — это вызывает мерцание прозрачных layered окон в Windows.
- Геометрия островка рассчитывается динамически в методе `BuildIslandGeometry(w, h)`:
  - Сверху выплывает плавной волной Безье из верхнего среза монитора (topWave = 18.0 DIP, BezierSegment).
  - Боковые стенки идут строго вертикально.
  - Снизу углы закругляются мягким радиусом 24.0 DIP.
- Сворачивание и разворачивание выполняется масштабированием (ScaleTransform) и cross-dissolve прозрачности без прямоугольных рывков.
- Размеры островка по вкладкам:
  - Controls: 540×320 DIP
  - Player: 480×146 DIP (выверенный отступ ~12 DIP под кнопками)
  - Standalone Player: 380×118 DIP (без строки вкладок)
  - Stats: 680×275 DIP
  - Apps: 520×435 DIP
  - Power: 540×140 DIP
  - Wallpaper: 720×246 DIP

3. КЛЮЧЕВЫЕ ПОДСИСТЕМЫ И ИХ РЕАЛИЗАЦИЯ
- ШТОРКА ПУНКТА УПРАВЛЕНИЯ (Controls Detail View):
  Внутри ControlsPanel реализована подстраничная навигация (ControlsMainView <-> ControlsDetailView).
  - Audio: перечисление через CoreAudio COM `IMMDeviceEnumerator`. Переключение дефолтного устройства вывода осуществляется через COM-интерфейс `IPolicyConfig.SetDefaultEndpoint(id, role)` без открытия настроек Windows! Иконка динамически меняется на наушники (\uE7F6) или динамик (\uE767).
  - Bluetooth: управление питанием через WinRT `Windows.Devices.Radios.Radio`, сканирование сопряжённых устройств через `DeviceInformation` и реестр `BTHENUM`, подключение через RFCOMM.
  - Wi-Fi: определение адаптеров через `NetworkInterface`, отображение статуса и сети.
- МЕДИАПЛЕЕР (SystemMediaService.cs):
  - Работает через WinRT `GlobalSystemMediaTransportControlsSessionManager`.
  - Подтягивает живые обложки (MemoryStream -> BitmapImage), название трека, автора.
  - Локальный таймер 100 мс плавно интерполирует шкалу воспроизведения.
- СИСТЕМНЫЙ МОНИТОРИНГ (HardwareMonitor.cs):
  - CPU: дельта времени ядра через `GetSystemTimes`.
  - RAM: `GlobalMemoryStatusEx`.
  - Disk: `DriveInfo`.
  - Network: дельта байт `NetworkInterface.GetIPStatistics()`.
  - Топ процессов по памяти и CPU.
- ОБОИ РАБОЧЕГО СТОЛА (WallpaperService.cs):
  - 3D Cover Flow карусель из 5 карточек.
  - Мгновенная установка через `SystemParametersInfoW(SPI_SETDESKWALLPAPER, 0, path, 3)`.
- ПИТАНИЕ:
  - Lock (`LockWorkStation`), Sleep (`SetSuspendState`), Restart/Shutdown (`shutdown.exe` с 15-секундным окном подтверждения и отменой `shutdown /a`).

- Для проверки UI генерировать превью через `dotnet run -c Release --no-build -- --render-preview "<директория>"` и анализировать полученные PNG.

```
